# 业务理解

- 软件名称：高职院校政策研究平台
- 产品定位：面向职业教育研究与管理工作的高职院校分布与职教政策数据服务平台，将全国高职院校基础信息、各省职教政策文件与五个维度分析可视化整合在一个平台内。
- 面向领域 / 行业：教育信息化 / 职业教育政策研究
- 核心价值：在同一平台内完成高职院校分布查询、职教政策检索与政策趋势分析，替代人工逐省查找教育厅网站和手工整理政策文件的工作方式。
- 证据文件：`业务理解证据.md`

## 目标用户

- 高职院校管理人员
- 职业教育研究者
- 教育行政部门工作人员
- 教育政策分析人员

## 主要业务功能

- 全国高职院校分布地图
- 院校信息检索与详情查询
- 职教政策数据库检索
- 政策自然语言智能搜索
- 政策数据管理（增删改查）
- 政策主题多标签标注
- 政策多维学术分析
- 院校统计交叉报表
- 多省政策自动采集

## 功能说明

- 全国高职院校分布地图：以中国地图热力形式展示全国31个省级行政区高职院校数量分布，支持按办学性质、主管部门、荣誉类别筛选，点击省份可查看该省院校列表
- 院校信息检索与详情查询：收录1540所专科院校，支持按名称、省份、办学性质、荣誉类别检索，查看院校的主管部门、官方网站、荣誉资质与舆情信息
- 职教政策数据库检索：收录全国31个省及教育部发布的职业教育政策文件，支持按省份、年份、12类主题标签筛选
- 政策自然语言智能搜索：支持以日常提问方式检索政策，如「去年广东关于产教融合的政策有哪些」，系统解析为筛选条件并返回匹配政策
- 政策数据管理（增删改查）：支持手动新增政策、编辑政策全文信息、删除政策以及调整政策主题标签
- 政策主题多标签标注：每项政策可标记2-4个主题标签，第一个为主标签，支持人工调整
- 政策多维学术分析：提供演进趋势、省份活跃度、主题共现、发文主体、密集度时序五个分析维度，以面积图、热力地图、共现矩阵、网络图、日历热力图呈现
- 院校统计交叉报表：按省份、办学性质、主管部门维度生成交叉统计报表，支持指标多选与TOP排名图表
- 多省政策自动采集：后台采集程序自动访问19个省级教育厅官网，采集职教政策并提取正文摘要、自动判定主题标签

## 典型操作流程

1. 用户进入平台首页查看全国高职院校分布地图
2. 通过点击省份或切换到院校详情页查询具体院校信息
3. 进入政策数据库页按条件检索或自然语言提问查找政策文件
4. 进入数据分析页查看院校统计报表与政策五维分析图表

## 操作手册结构建议

1. 平台以全国高职院校地图为首页入口，四大功能模块通过顶部导航切换；院校详情与政策数据库面向查询场景，数据分析面向研究场景。
2. 政策数据库支持传统条件筛选与自然语言提问两种检索方式，检索结果以卡片列表呈现，点击可查看政策全文信息。

## 操作手册页面/流程模块

1. 院校分布地图：打开平台即默认显示
   - 使用场景：研究者想快速了解某省高职院校总体规模，或从地图出发进入某个省份的院校列表
   - 操作要点：打开平台后默认进入地图页面，观察各省颜色深浅判断院校数量规模，颜色越深表示院校数量越多；在页面左侧筛选栏选择办学性质（公办/民办/中外合作办学）、主管部门或荣誉类别，地图热力与统计数字随筛选即时更新；将鼠标悬停在省份上查看该省院校总数、公办民办数量与双高院校数量；点击某个省份，页面右侧弹出该省院校列表抽屉，抽屉内按院校名称排列
2. 院校详情查询：顶部导航点击「院校详情」
   - 使用场景：用户需要查找某所院校的主管部门、官网地址、荣誉资质或公众舆情
   - 操作要点：在顶部导航点击「院校详情」进入查询页；在搜索框输入院校名称关键词，如「职业技术学院」，列表显示名称匹配的院校卡片；使用省份下拉、办学性质下拉与荣誉下拉进一步缩小范围，多个条件同时生效；点击院校卡片打开详情弹窗，弹窗展示院校标识码、主管部门、所在地、办学性质等基本信息
3. 政策数据库检索：顶部导航点击「政策数据库」
   - 使用场景：研究者查找某省某年度关于产教融合的政策文件，或了解政策全文摘要
   - 操作要点：在顶部导航点击「政策数据库」进入政策库；在自然语言搜索框输入问题，如「去年湖南关于产教融合的政策有哪些」，点击「智能分析」按钮，系统将问题解析为省份、年份与主题标签筛选条件并展示在结果区上方；也可以不使用智能分析，直接在下方的省份下拉、年份下拉中选择条件，或点击12个主题标签按钮（治理体系、产教融合、人才培养等）进行组合筛选；筛选结果以卡片列表展示，每张卡片显示发布日期、政策标题、所属省份、主题标签与摘要
4. 政策数据管理：政策数据库页顶部「＋新增政策」按钮；政策详情弹窗「编辑信息」「编辑标签」「删除」按钮
   - 使用场景：数据维护人员发现政策信息有误或需要补充新政策时进行人工维护
   - 操作要点：点击「＋新增政策」填写必填字段并选择主题标签后保存；在政策详情弹窗点击「编辑信息」修改政策全文信息；点击「编辑标签」增删主题标签，最多4个，第一个为主标签；点击「删除」并在确认提示中确认删除
5. 政策多维分析：顶部导航点击「数据分析」，再点击「政策分析」子标签
   - 使用场景：研究者撰写政策研究材料时查看政策演进趋势、省份对比、主题关联、发文主体结构与发布季节规律
   - 操作要点：点击「政策分析」进入分析页；在演进趋势查看各年度各主题政策数量变化；在省份活跃度对比各省发布量并查看地图热力；在主题共现切换矩阵图或网络图查看主题关联
6. 院校统计报表：顶部导航点击「数据分析」，默认进入「院校统计」子标签
   - 使用场景：管理者需要各办学性质或主管部门的院校数量对比数据
   - 操作要点：在顶部导航点击「数据分析」，默认进入「院校统计」子标签；在左侧配置栏选择行维度：省份、办学性质或主管部门；勾选需要统计的指标：院校数量、公办数量、民办占比、双高院校、双高占比，可多选；点击「生成报表」按钮，右侧显示对应维度的 TOP10 柱状图与举办性质分布饼图
